# RandomForestRegressorModelGearbox
This is simple code I used to to build and train RandomForestRegressor model for Gearbox unit to predict condition and mech parameters at different operating modes. 
The increased vibration detected on the gearbox casing.
The influence of the rotational speed on the casing vibration level (resonant frequencies) has been identified.
Recommendations have been provided for optimizing the operating mode.
